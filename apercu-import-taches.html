Import de tâches — comment ça fonctionne

Trois étapes. Les colonnes, les statuts et les messages d'erreur ci-dessous sont produits par l'analyseur réellement en place.

Le principe : rien n'est créé tant que le fichier n'est pas correctLe système analyse d'abord, montre ce qu'il a compris, et n'enregistre qu'après votre confirmation. Si une seule ligne est fautive, aucune tâche n'est créée.
1

Télécharger le modèle

Fichier Excel généré à la demande, avec les colonnes attendues et une ligne d'exemple bâtie sur vos propres projets.
